CléTypeTTL

            
            

              
              
            

          

          

            
Sélectionnez une clé.

          

        

        

          

            
            
          

          
          
Lecture seule par défaut. KEYS est refusée (utilisez SCAN).
Exemples (écriture : activer le mode avancé) :
  SET ma:cle bonjour     crée une clé
  GET ma:cle             lit la clé ; (nil) = la clé n'existe pas
  EXPIRE ma:cle 60       expire dans 60 s · TTL ma:cle : temps restant
  SCAN 0 MATCH ma:* COUNT 100   liste les clés
  DEL ma:cle             supprime · INFO memory : mémoire utilisée
